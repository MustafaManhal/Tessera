# Hook reference fixtures

Read 2026-11-11. These are minimal anonymized forms of current official documentation input schemas/examples, not live model-session captures. No real user settings were read. `settings.before` files are synthetic coexistence fixtures. `settings.after` files are generated by the implementation from these inputs.

Claude: https://code.claude.com/docs/en/hooks and https://code.claude.com/docs/en/hooks-guide
Gemini: https://geminicli.com/docs/hooks/reference/ and https://geminicli.com/docs/hooks/
Codex: https://developers.openai.com/codex/config-advanced and https://developers.openai.com/codex/config-reference

Codex supplies its JSON as the final argv element, not stdin. Its file is named `.json` here for transport-independent inspection. Gemini `BeforeAgent`/`BeforeTool`/`AfterAgent` are the documented counterparts of submission/tool/stop events; notification `ToolPermission` reports attention.
