Privacy policy

Last updated: 11 November 2026.

Short version: Tessera does not collect, send or sell any data about you or your computer. There is no telemetry, no analytics and no account.

The app

  • Your terminal sessions, scrollback, settings and projects stay on your computer, in the app's data folder.
  • Tessera does not phone home. The only network requests it makes on its own are the check for a new version (to GitHub Releases) and the download of that update.
  • Programs you run inside Tessera, including coding agents, are separate software. They may contact their own services under their own terms and privacy policies. Tessera does not read or forward what they send.

Optional features

These do nothing until you turn them on.

  • GitHub sign-in uses GitHub's device flow. The access token is stored in your operating system's keychain and is used only to talk to GitHub for you.
  • Sync stores your settings and workspaces on a server run by the project (Cloudflare). The data is encrypted on your device before it is uploaded, so the server only holds data it cannot read.

This website

  • No cookies, no analytics and no trackers.
  • The download buttons ask GitHub's public API for the latest release when the page loads, so GitHub sees your IP address as it would on any page of github.com. See GitHub's privacy statement.
  • The site is hosted on Vercel, which keeps standard server logs. See Vercel's privacy policy.
