Code signing policy

Last updated: 11 November 2026.

Windows

Windows installers of Tessera are signed through the SignPath Foundation: free code signing provided by SignPath.io, certificate by SignPath Foundation. The project has applied to the programme. Until it is approved, Windows installers are not signed and SmartScreen shows "unknown publisher".

  • Only builds made from the public source code at github.com/MustafaManhal/Tessera are submitted for signing.
  • Builds are made by GitHub Actions from the main branch or a version tag. No build made on a personal computer is signed.
  • The signing request is made by the release workflow and can be traced to a commit. The maintainer approves each release before it is signed.

Team roles

  • Author, reviewer and approver: Mustafa Manhal (@MustafaManhal), the sole maintainer.

macOS

macOS builds are signed ad hoc and are not notarized (notarization needs a paid Apple Developer membership). The first time you open the app, right-click it and choose Open.

Update signatures

Separately from operating system signing, every update the app installs is verified against a public key built into the app. The matching private key is held only by the maintainer.

Privacy

Signed programs do not transmit any information to the signing service beyond what is needed to sign the file. See the privacy policy.
