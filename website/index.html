One terminal for every coding agent

Tessera is a fast, open-source terminal for macOS and Windows. Run Claude Code, Codex, Gemini CLI and more side by side, each in its own git worktree.

Say it: TESS-er-uh (a small tile of a mosaic)

Built for the way you work now

Early development: the terminal, blocks, tabs, splits, themes and worktree tasks work today. Built-in agent launching is the next milestone.

Command blocks

Every command becomes a block with its exit status and duration. Jump between prompts, copy a block's output, re-run it, or fold it away.

Tasks in git worktrees

Start a task and Tessera makes a worktree and branch for it. Run several agents on one repo without them stepping on each other.

Tabs, splits and restore

Tabs, splits, broadcast input and multiple windows. Quit and come back to your layout, directories and scrollback.

Fast and native

A Rust core and a GPU-drawn terminal. Output keeps up with a 100 MiB flood, and the terminal host answers keystrokes in well under a millisecond.

Your shell, your editor

zsh, bash, fish, PowerShell and WSL. Open a task in VS Code, Cursor, Zed or JetBrains, and run project scripts in named panes.

Private by default

No telemetry, no account. Settings live in a plain config.toml. Read the privacy policy.

Install notes

macOS

Open the .dmg and drag Tessera to Applications. The app is not notarized yet, so the first time, right-click it and choose Open. If macOS still refuses, run:

xattr -dr com.apple.quarantine /Applications/Tessera.app

Windows

Run the -setup.exe installer. Until the project's code signing is approved, Windows SmartScreen shows "unknown publisher": choose More info, then Run anyway. See the code signing policy.

Updates

Tessera checks for new versions and verifies every update with a signature before installing it. This page always links the newest release.
